# Fallout34 0.9.148 한국어 원본 ESM 시험

**실험용이며 전체 설치와 인게임 안정성은 검증되지 않았습니다.** 일반 한패 설치기에는 변환기 실행 파일이 포함되지 않습니다.

사용자 PC의 한글 Fallout 3 원본으로 0.9.148의 플러그인 단계만 별도 폴더에서 실행하면, 원본 변환기의 `f34.esm.Subrecord.zstr`에서 CP1252 디코딩 오류가 재현됐습니다. 게임 Data에 결과를 설치하지 않았습니다.

첫 복사본 시험은 해당 오류를 넘겼지만, PATH에 잡힌 구형 DirectX SDK `texconv`로 인해 후반 텍스처 처리에서 실패했습니다. 설치기에 동봉된 DirectXTex `payload/bin/texconv.exe`를 지정해 재시험한 폴아웃 3과 뉴 베가스 플러그인 단계는 각각 종료 코드 0으로 완료됐습니다. 두 ESM에 한패를 적용해 구조와 지형 보존을 확인했습니다. 전체 설치와 게임 내 동작을 검증한 결과는 아닙니다.

`tools/patch_fallout34_09148_utf8.py`는 해당 버전 바이너리의 정확한 SHA-256과 세 함수의 상수 위치를 확인한 다음 별도 실행 파일을 생성합니다. 기존 0.9.102 시험과 같이 입력 문자열, 출력 문자열 및 FO3 게임 설정에서 쓰는 인코딩을 UTF-8로 바꿉니다. 원본을 덮어쓰거나 생성된 실행 파일을 배포하지 않습니다.

이 방법은 CP1252 폴백이 아닙니다. CP1252만 사용하는 다른 입력이나 아직 살펴보지 못한 경로에서 실패 또는 글자 손실이 생길 수 있습니다. 새 ESM의 구조·텍스트·전체 설치와 게임 내 동작을 별도로 검증해야 합니다. 0.9.148 이외의 실행 파일에는 적용할 수 없습니다.
